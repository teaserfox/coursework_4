# 💼 Vacancy Parser

### Object-oriented application for collecting and processing job vacancies

Учебный Python-проект по объектно-ориентированному программированию.

Приложение получает вакансии с **HeadHunter** и **SuperJob**, приводит данные из разных API к единой модели и предоставляет инструменты для фильтрации, сортировки и сохранения результатов.

---

## 🚀 Возможности

* поиск вакансий через HeadHunter и SuperJob;
* выбор одной или обеих платформ;
* постраничное получение результатов;
* преобразование данных разных API в единую модель `Vacancy`;
* сохранение исходных данных в JSON;
* фильтрация по ключевому слову;
* фильтрация по уровню зарплаты;
* фильтрация по региону;
* фильтрация по опыту работы;
* сортировка вакансий по минимальной зарплате;
* формирование топ-N вакансий;
* удаление вакансий из текущего результата;
* сохранение итоговой выборки в JSON.

---

## 🏗️ Архитектура

В проекте используется объектно-ориентированный подход с разделением ответственности между основными классами.

```text
HeadHunter API ──┐
                 ├──> Vacancy ──> filtering ──> sorting ──> results
SuperJob API ────┘
                      │
                      ▼
                  JSON storage
```

Для работы с API реализован общий абстрактный класс `Engine`, от которого наследуются клиенты HeadHunter и SuperJob.

Это позволяет работать с разными источниками вакансий через схожий интерфейс.

### Основные компоненты

**`hh_sj_classes.py`**

Работа с API HeadHunter и SuperJob.

* абстрактный класс `Engine`;
* `HeadHunterAPI`;
* `SuperJobAPI`;
* получение вакансий постранично.

**`vacancy_class.py`**

Единая модель вакансии.

Хранит название, зарплату, регион, требования, описание, опыт работы и ссылку на вакансию.

Также реализованы операторы сравнения вакансий по минимальной зарплате.

**`json_class.py`**

Работа с JSON:

* сохранение данных API;
* чтение вакансий;
* преобразование данных разных API в объекты `Vacancy`;
* фильтрация по зарплате;
* работа с результатами поиска.

**`ut/main.py`**

Интерактивный пользовательский сценарий приложения.

## 🔄 Как работает приложение

1. Пользователь выбирает источник вакансий:

   * HeadHunter;
   * SuperJob;
   * оба источника.

2. Вводит поисковый запрос.

3. Приложение получает вакансии через API.

4. Данные сохраняются в JSON.

5. Ответы разных API преобразуются в единую модель `Vacancy`.

6. Пользователь может последовательно применить фильтры.

7. Результаты сортируются по минимальной зарплате.

8. При необходимости формируется топ-N вакансий.

9. Результат можно вывести в консоль или сохранить в JSON.
